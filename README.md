# RallyLens 网页可视化

这是一个在 `E:\tennis` 中从零建立的独立网页，不读取、迁移或依赖任何旧 RallyLens 网页代码。

## 启动

在 PowerShell 中运行：

```powershell
E:\tennis\rallylens-web\start.ps1
```

浏览器会打开 `http://127.0.0.1:4173/`。按 `Ctrl+C` 停止服务。内置服务支持视频区间读取，因此可以直接拖动时间轴或点击关系切片跳转。

## 当前数据范围

- 双视角素材：`组1-阶段1-01-02-S1.MP4` 与 `组1-阶段1-02-01-S1.MP4` 的 45 秒网页代理片段。
- 实时数据：`optimized_relations_v3` 中 G01-S1 阶段 A 的 45 个约一秒关系切片。
- 阶段比较：`stage_metrics_v3.csv` 中同一组别 A / B / C / D 四阶段的冻结值。
- 指标语义：`metric_catalog.json` 定义的完整 16 项关系指标。

其中 11 项指标具有实时与阶段输出，4 项只有阶段输出；“失误后重复机会”仍按审计结论保持阻断和空值，不用零值代替。七种关系状态来自无监督聚类，后验置信度只表示聚类归属把握，不等同于语义正确率。

## 形状语义

- 左右两个活动体：P1 与 P2 在同一时刻对双方关系状态的承载，而不是两份个人成绩。
- 十一项真实轴：每项实时指标占据一个固定轴，转换后的指标值直接决定该顶点离中心的距离。配合成本与关系漂移使用反向轴，因此向外分别表示成本更低、漂移更低。
- 整体面积：由十一处顶点共同形成，不使用一个合成分数替代原始多维关系；大轮廓表示更多维度同时向外展开。
- 距离与重叠：共同可训练性、舒适可练区、回应互惠、共同调节和节奏协同共同决定两形状的中心距离；深色区域由两个实时多边形做真实几何求交得到。重叠越多表示这五项关系靠近代理同时较高，不等同于关系质量结论。
- 均衡与失衡：所有顶点只用直线相连，不使用圆角或曲线平滑。十一项接近时自然形成较规则的多边形；单项特别高或低时自然形成尖峰或内凹。
- 目标并集：先分别生成 P1 与 P2 的目标轮廓，再用一个无边框浅色实体呈现两者的几何并集。
- 指标卡片：11 张实时指标卡及 1 张目标并集卡位于视频下方、图形左侧。默认没有小球；选择实时指标后，只在双方对应真实顶点显示黑色标记；缺失指标显示黑色叉号而不是伪造数值。

上方形状逐轴使用全部 11 项实时指标；挑战适配、搭档增量贡献、关系韧性、阶段迁移保留及阻断指标仅保留在下方完整 16 项数据区。所有实时形状和关系切片都在相邻秒级切片之间连续插值，不在切片边界突变。

## CHI / CSCW 方法转换

“关系对照图谱”不再把 16 项指标强制放入同一种图形，而是根据时间尺度、证据来源和数值方向选择呈现形式。

- 并置与叠合：四阶段分别保留 P1、P2 和共同交集三层，不把关系压成一个总分。
- 同尺度小倍图：四张多边形使用完全相同的十一轴、方向、半径和距离映射；图形差异只能来自阶段数据与真实缺失。
- 片段动态折线：有效练习机会、配合成本、共同可训练性、双方舒适可练区、节奏协同和关系漂移使用当前 45 秒视频片段的连续变化；不外推为完整阶段或整局。
- 阶段柱状比较：回应转化、回应互惠、共同调节、角色流动性和关系韧性使用 A/B/C/D 冻结汇总，因为逐秒值稀疏、波动或本身只在阶段层成立。
- 目标与反馈：目标匹配暴露和挑战适配只比较 B/C；A/D 没有对应目标或反馈时保持空白。
- 特殊证据：搭档增量贡献使用 −10% 至 +10% 正负发散图；阶段迁移保留使用 D 阶段单值参照；失误后重复机会只显示阻断原因。
- 联动：折线播放头与视频同步；点击阶段轮廓会高亮所有阶段图和完整矩阵；点击任一图表会打开该指标的定义与 A/B/C/D 原值。
